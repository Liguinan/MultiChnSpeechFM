# MultiChnSpeechFM
Multichannel speech foundation model for speech enhancement front-end.

Recipe configs use placeholder paths. Replace them with your local directories before training or decoding:

- `/path/to/data` — simulated multichannel LibriSpeech (rx1.5)
- `/path/to/data_simulation` — simulated multichannel LibriSpeech (pretraining)
- `/path/to/MultiChnSpeechFMExperiments` — pretrained / MoE checkpoints
- `/path/to/MultiChnSpeechFMExperiments_DOA` — DOA experiment checkpoints
